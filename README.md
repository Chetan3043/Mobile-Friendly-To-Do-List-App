# 📱 Mobile-Friendly To-Do List App

A simple, elegant, and **mobile-responsive To-Do List Web Application** built using **HTML, CSS, and JavaScript**.  
The app is fully optimized for smartphones and tablets using **CSS media queries**.

---

## 🚀 Features

- ✅ Add and delete tasks dynamically  
- 📱 Fully responsive design for all screen sizes  
- 🎨 Beautiful gradient and glassmorphism UI  
- ⚡ Lightweight — no frameworks or libraries used  
- 🧩 Clean and beginner-friendly code structure  

---

## 🧠 Technologies Used

- **HTML5** – Page structure  
- **CSS3** – Styling and responsiveness  
- **JavaScript (Vanilla)** – Logic for adding/deleting tasks  
- **Media Queries** – Mobile optimization
